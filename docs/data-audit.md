# Data audit

Every number the story states, where it comes from, and whether it was reproduced. All values are
generated by `scripts/build_data.py` into `data/derived/headline.json` and checked by
`scripts/validate.py` (last run 26 Oct 2026: all checks passed). Numbers written in `index.html` and
`methods.html` carry `data-h` keys and are compared to `headline.json` on every build.

Status: **Reproduced** = recomputed from the supplied tables and matches the storyboard value.
**Revised** = recomputed, and the storyboard or earlier site value was changed. **Retired** = not
supported; removed from the public story.

## Checks the build runs

See `docs/pipeline.md` for the full list. In summary: unique keys and 5-digit FIPS; Jan 2019–Jul 2026
monthly coverage with no gaps; monthly panel agrees with the county table in May 2022 and Jul 2026;
the exact expected missing rows; zero OB-GYN counts preserved and distinct from missing;
`drive_miles_change = jul2026 − may2022` (exact in the supplied data: max difference 0.000 mi); non-negative
distances and counts; catchment reconciliation including DC; per-clinic values never infinite;
burden shares sum to 100%; the 316-of-589 and rurality numbers recomputed independently; and every
`data-h` number in the HTML equal to `headline.json`.

## Not verifiable from this repository

The supplied tables were produced by `build_final.py` from raw downloads that are not in this
repository (see `data/source/PROVENANCE.md`). Values such as the Myers road distances, AHRF counts
and Guttmacher tiers are taken as supplied. Recomputing them requires the upstream script and
raw files.
